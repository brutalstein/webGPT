# Yol Haritası

## Tamamlanan temel katmanlar

- Gemini için kalıcı Chrome/CDP provider
- SQLite konuşma ve kalıcı bellek
- Sandbox'lı dosya ve terminal araçları
- İnsan onaylı yazma/komut akışı
- Yerel React agent web çalışma alanı
- Tool activity timeline ve görünür yanıt snapshot akışı

## Sonraki gelişmeler

- AST/LSP tabanlı sembol arama ve güvenli refactor araçları
- Unified diff editörü ve değişiklik önizleme/onay ekranı
- Uzun süren komutlar için gerçek zamanlı stdout/stderr stream'i
- Proje bazlı semantic index ve incremental file watcher
- Git diff, stage ve commit için ayrı yüksek seviyeli araçlar
- Session etiketleri, arşivleme ve çalışma alanına göre gruplama
- Provider sağlık ölçümleri ve otomatik fallback
- Performans/latency dashboard'u ve event trace dışa aktarma
